## Бой

Запись: **ДВ ДВ ДВ ДВ** (Д — вниз, В — вверх, «-» — рука проходит мимо струн)

```
Счёт:   1  и  2  и  3  и  4  и
Бой:    ↓  ↑  ↓  ↑  ↓  ↑  ↓  ↑
Акцент: >     >     >     >
```

Этот рисунок совпал в 71 из 124 тактов. В остальных — вариации, обычно на сменах частей.

Рука двигается как маятник без остановок: вниз на счёт, вверх на «и». Там, где точка, рука всё равно делает движение, просто не задевает струны.

## Слух против зрения

Видеоанализ не запускался (нет `ANTHROPIC_API_KEY` или видео). Аккорды и бой — только по звуку.

## Как выучить

1. Поставьте аккорды Am, Em и переставляйте их по кругу без ритма, пока смена не станет занимать меньше доли.
2. Бой «ДВ ДВ ДВ ДВ» сначала на одном заглушённом аккорде, под метроном 75 BPM.
3. Соедините: квадрат + бой на медленном темпе, затем поднимайте до 108 BPM.
4. Играйте вместе с видео — на сменах частей слушайте, где бой меняется.
