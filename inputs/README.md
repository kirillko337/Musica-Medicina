Сюда можно загрузить видео или аудио (mp4, mov, mp3, wav, m4a…), если YouTube не отдаёт ролик серверу GitHub.
После загрузки разбор запустится сам и появится в папке `guides/`.

Через сайт GitHub: **Add file → Upload files** (до 25 МБ). Видео с лицом и руками лучше 720p — так Claude разглядит аккорды.
