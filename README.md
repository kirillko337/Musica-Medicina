# Musica Medicina — разборы песен на гитаре

Кидаете ссылку на YouTube и через 5–10 минут получаете разбор: аккорды со схемами, каподастр, последовательность по тактам и бой. Если в кадре видны руки, бот сверяет то, что услышал, с тем, что видно на видео.

## Как запустить

**С телефона.** Issues → New issue → «Разбор песни» → вставить ссылку → Submit. Бот ответит в этом же issue, а гайд сохранит в `guides/<название>/README.md`.

**Вручную.** Actions → «Разбор песни» → Run workflow → вставить ссылку. Там же можно задать название и темп, если автоматика ошиблась вдвое.

**Своим файлом.** Если YouTube не отдаёт ролик серверам GitHub, скачайте видео и загрузите его в папку `inputs/` (Add file → Upload files). Разбор запустится сам.

## Что нужно настроить один раз

Settings → Secrets and variables → Actions → New repository secret:

| Секрет | Зачем | Без него |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude смотрит на кадры: форма аккорда, каподастр, где правая рука | разбор только по звуку |
| `YT_COOKIES` | YouTube иногда просит у серверов GitHub «подтвердить, что вы не робот» | часть роликов не скачается, тогда помогает загрузка в `inputs/` |

Как достать cookies: в Chrome поставить расширение «Get cookies.txt LOCALLY», открыть youtube.com под своим аккаунтом, экспортировать и вставить содержимое файла в секрет. Лучше завести для этого отдельный Google-аккаунт.

## Как это работает

```
YouTube ─ yt-dlp ─► видео 720p ─┬─► звук ─► librosa ─► темп, доли, тональность
                                │                    ─► аккорды (хрома + бас + Витерби)
                                │                    ─► удары по струнам ─► сетка 8-х/16-х ─► рисунок боя
                                │
                                └─► кадры ─► Claude ─► каподастр, форма аккорда в каждом фрагменте
                                          ─► OpenCV ─► движение правой руки: вниз или вверх в момент удара
                                                         │
                                       сверка звук ↔ видео ◄┘ ─► guides/<песня>/README.md + analysis.json
```

**Аккорды по звуку.** Звук делится на гармоническую и ударную части. По гармонической считается хрома: сколько энергии у каждой из 12 нот на каждой доле. Каждая доля сравнивается с шаблонами мажорных и минорных аккордов, а бас подсказывает корень. Алгоритм Витерби сглаживает результат, чтобы аккорд не прыгал на каждой доле. Септаккорды включаются флагом `--sevenths`.

**Каподастр.** По звуку видно только то, что реально звучит. Скрипт перебирает каподастр от 0 до 7 и выбирает вариант, при котором больше всего аккордов ложится в открытые формы. Если каподастр видно на видео, приоритет у видео.

**Бой.** Удары по струнам ищутся в ударной части звука и раскладываются по сетке долей. Повторяющийся в большинстве тактов рисунок и есть бой. Направление задаёт «маятник»: на счёт рука идёт вниз, на «и» вверх. Так играет почти любой гитарист.

**Зачем видео.** Звук хорошо отвечает на вопрос «когда ударили», но плохо на вопрос «вниз или вверх». Здесь помогает правая рука в кадре. Claude находит зону, где она бьёт по струнам, а OpenCV считает её вертикальное движение в момент каждого удара. В гайде есть таблица «Слух против зрения»:

- совпадение аккордов: форма по звуку с учётом каподастра против формы, которую Claude видит на грифе. Claude не показывают версию по звуку, чтобы сравнение было честным;
- направление ударов: «маятник» против движения руки на видео;
- направление ударов: акустический признак против видео.

Где звук и видео расходятся, а Claude уверен в своём ответе (≥0.8), в гайд идёт версия с видео.

## Точность и ограничения

Проверено на синтетических записях, где аккорды и бой известны заранее (`tests/`):

- аккорды: 99–100% долей;
- темп: ±3% от заданного;
- рисунок боя: совпал полностью («Д-ДВ-ВДВ», «Д-Д-ДВДВ»);
- направление удара по движению руки: 100% на тестовом видео;
- направление удара только по звуку: 60–70%. Это слабый признак, поэтому он лишь подтверждает «маятник».

На живых записях точность будет ниже: вокал, второй инструмент, реверб, нестандартный строй. Самые частые ошибки:

- путаются Am и C, Em и G: у них по две общие ноты. Видео такие ошибки обычно ловит;
- темп получается вдвое быстрее или медленнее. Лечится параметром `bpm` при ручном запуске;
- перебор вместо боя: рисунок не находится, и гайд говорит об этом прямо.

## Локальный запуск

```bash
pip install -r requirements.txt          # нужен ещё ffmpeg
export ANTHROPIC_API_KEY=...             # необязательно
python -m guitar_guide "https://youtu.be/..."         # или путь к файлу
python -m pytest -q tests                # тесты на синтетике
```

Модель для видео задаётся переменной `GUIDE_MODEL` (по умолчанию `claude-opus-5-5`). На одну песню уходит до 25 запросов с кадрами, это лимит `--max-vision-calls`.
