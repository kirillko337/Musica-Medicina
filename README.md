# Musica Medicina — разборы песен на гитаре

Кидаете ссылку на YouTube и через 5–10 минут получаете разбор: аккорды со схемами, каподастр, последовательность по тактам и бой. Если в кадре видны руки, бот сверяет то, что услышал, с тем, что видно на видео.

## Как запустить

**С телефона.** Issues → New issue → «Разбор песни» → вставить ссылку → Submit. Бот ответит в этом же issue, а гайд сохранит в `guides/<название>/README.md`.

**Вручную.** Actions → «Разбор песни» → Run workflow → вставить ссылку. Там же можно задать название и темп, если автоматика ошиблась вдвое.

**Своим файлом.** Если YouTube не отдаёт ролик серверам GitHub, скачайте видео и загрузите его в папку `inputs/` (Add file → Upload files). Разбор запустится сам.

## Что нужно настроить один раз

Settings → Secrets and variables → Actions → New repository secret:

| Секрет | Зачем | Без него |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude смотрит на кадры: форма аккорда, каподастр, где правая рука | разбор только по звуку |
| `YT_COOKIES` | YouTube иногда просит у серверов GitHub «подтвердить, что вы не робот» | часть роликов не скачается, тогда помогает загрузка в `inputs/` |

Как достать cookies: в Chrome поставить расширение «Get cookies.txt LOCALLY», открыть youtube.com под своим аккаунтом, экспортировать и вставить содержимое файла в секрет. Лучше завести для этого отдельный Google-аккаунт.

## Как это работает

```
YouTube ─ yt-dlp ─► видео ─┬─► кадры ─► Claude ─► подписи на экране: названия и схемы аккордов, каподастр
                           │                    ─► каподастр, форма аккорда в каждом фрагменте
                           │          ─► OpenCV ─► движение правой руки (вниз/вверх)
                           │
                           └─► звук ─► Demucs / UVR ─► гитара без голоса
                                     ─► beat_this / madmom ─► доли, сильные доли, размер, темп по ходу песни
                                     ─► хрома + Витерби (+ словарь с экрана) ─► аккорды
                                     ─► basic-pitch ─► ноты ─► струны по аппликатуре ─► перебор (p-i-m-a, таб)
                                                          └─► по каждому такту: перебор или бой ─► части песни
                                     ─► огибающая атак ─► рисунок боя (только в частях с боем)
                                                          ─► guides/<песня>/README.md + analysis.json
```

**Доли и такты.** Нейросеть beat_this (CPJKU, 2024), запасной вариант — madmom. Обе дают не только доли, но и начало такта, поэтому сетка для боя и перебора стоит правильно даже на живой записи, где темп плавает. Темп в гайде показан по ходу песни: «69 → 82 BPM».

**Аккорды.** Хрома по гитаре без голоса, шаблоны аккордов, бас подсказывает корень, Витерби сглаживает. Два уточнения:
- *подписи на экране.* Многие уроки показывают аккорды и схемы. Claude читает их с кадров, и распознавание выбирает только из этих аккордов. Сдвиг относительно звука (0–7 ладов) — это каподастр;
- *аккорд без терции.* Если звучат только тоника и квинта (D-A-D), мажор это или минор, по звуку не понять. Такой аккорд называем по тональности песни: в ре миноре D5 → Dm.

**Перебор.** basic-pitch переводит звук в ноты, каждая нота привязывается к струне по аппликатуре текущего аккорда. Ноты, которые просто продолжают звенеть, отсеиваются по приросту громкости. Затем по всем тактам с одинаковой басовой струной берётся самая частая струна на каждой позиции, в два прохода: второй — только по тактам, похожим на черновой рисунок. В гайде схема записана струнами, пальцами p-i-m-a и табулатурой.

**Бой или перебор.** Бой — удары по 3+ струнам разом, перебор — по одной-две. Стиль такта решается по соседним тактам, так песня делится на части: «0:01–0:57 перебор, 1:00–3:21 бой».

**Бой.** Удары ищутся в ударной части звука и раскладываются по сетке. Если в бое есть одиночный бас большим пальцем, это игра пальцами «бас + удар», и правило маятника не применяется. Атаки без гитарных нот (бубен, хлопки) отбрасываются.

**Каподастр.** По подписям на экране, иначе по видео, иначе перебором 0–7 ладов под открытые формы.

**Аппликатуры.** Если в ролике есть схемы аккордов, в гайде именно они: так играет сам автор. Для баррэ предлагается облегчённая форма (мини-F, Bm7).

## Точность и ограничения

Проверено на синтетике (`tests/`) и на живом уроке He Yama Yo (гитара, голос, бубен), где ответ известен по ручному разбору:

| Что | Было | Стало |
|---|---|---|
| Темп и такты | librosa: 108 BPM при реальных 69, сетка съехала | madmom: начало каждого такта совпало с ручной разметкой |
| Аккорды по тактам (17 известных) | 12 из 17: Dm без 1-й струны распознавался как D | 16 из 17, с подписями экрана 17 из 17 и точные A7, Am7 |
| Перебор | не распознавался | Dm: 4-3-2-3 4-3-2-3, p-i-m-i, как в ручном разборе |
| Части | — | перебор 0:01–0:57, бой с 1:00 (бубен вступает на 0:50) |
| Бой | рисунок по всей песне вместе с перебором | только в части с боем: бас на «4», удары на «а» и «и», бубен отсеян |

Ограничения:
- ноты basic-pitch на живой записи с перкуссией шумные: схема перебора совпадает примерно в половине тактов, гайд пишет это прямо;
- указательный и средний по звуку не различить: p-i-m-a — стандартная классическая расстановка под струны;
- ровный перебор восьмыми трекер иногда считает вдвое быстрее; это ловится (на полудолях нет нот) и исправляется;
- путаются Am/C и Em/G, если нет ни подписей, ни видео грифа.

## Локальный запуск

```bash
pip install -r requirements.txt          # нужен ещё ffmpeg
pip install --no-deps -r requirements-notes.txt   # basic-pitch без TensorFlow
pip install torch --index-url https://download.pytorch.org/whl/cpu && pip install -r requirements-ml.txt  # необязательно
export ANTHROPIC_API_KEY=...             # необязательно
python -m guitar_guide "https://youtu.be/..."         # или путь к файлу
python -m pytest -q tests                # тесты на синтетике
```

Модель для видео задаётся переменной `GUIDE_MODEL` (по умолчанию `claude-opus-5-5`). На одну песню уходит до 25 запросов с кадрами, это лимит `--max-vision-calls`.
